# Contributing

Open an issue describing the behavior and evidence before expanding scope. Keep each change focused, preserve offline demos and add adversarial tests for changed authorization or state transitions. Use only synthetic fixtures. Never commit tokens, private keys, credentials, raw account inventories or personal data.

Run the checks in the README, regenerate schemas with `python -m app.cli schemas`, and capture sample output by executing the CLI. Explain semantic output variation for cryptographic material. CI actions must remain SHA-pinned with least-privilege permissions. Document any unverified provider capability. Maintain clear descriptions and avoid unsupported security or performance claims.
